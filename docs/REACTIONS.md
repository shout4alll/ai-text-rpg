# 리액션 · 마음 리액션 · 호감도

모든 목록은 **`config/reactions.ts`** 한 파일에 있습니다. 항목을 추가하면 AI 프롬프트와 응답 스키마에 자동으로 반영됩니다.

## 1. 화면 리액션 (상대가 보여 주는 반응)

AI가 답장마다 하나를 고르면, 화면이 다음 순서로 반응합니다.
1. 해당 인물 폴더에 **리액션 id와 같은 이름의 영상**이 있으면 그 영상을 재생합니다.
2. 없으면 "영상 찾는 순서"의 다음 이름을 차례로 찾습니다.
3. 하나도 없으면 화면 움직임과 효과로 대신합니다.

| id | 이름 | 영상 찾는 순서 | 영상이 없을 때 움직임 | 효과 |
| --- | --- | --- | --- | --- |
| `idle` | 평소 | (기본 루프) | — | — |
| `smile` | 미소 | smile → happy → nod | 살짝 확대 | — |
| `laugh` | 웃음 | laugh → happy | 통통 튐 | ✨ |
| `nod` | 끄덕 | nod | 끄덕임 | — |
| `shake` | 도리도리 | shake | 좌우 흔들림 | — |
| `shy` | 쑥스러움 | shy → smile → happy | 고개 갸웃 | 💗 + 분홍빛 |
| `love` | 설렘 | love → shy → happy | 확대 | ❤️💕 + 붉은빛 |
| `pout` | 삐짐 | pout → angry → shake | 흔들흔들 | 💢 |
| `surprised` | 놀람 | surprised | 확대 | ❗ |
| `sad` | 속상함 | sad → shake | 가라앉음(채도↓) | 💧 + 어두운 톤 |
| `touched` | 감동 | touched → sad → smile | 살짝 가라앉음 | ✨ + 따뜻한 빛 |
| `thinking` | 생각 중 | thinking → idle | 고개 갸웃 | 💭 |
| `excited` | 신남 | excited → laugh → happy | 통통 튐 | 🎉 |
| `comfort` | 토닥임 | comfort → nod | 부드러운 끄덕임 | 🤍 |
| `sleepy` | 졸림 | sleepy → idle | 살짝 가라앉음 | 💤 |
| `turn_away` | 등 돌림 | turn_away → pout → shake | 흔들흔들 | 💢 + 어두운 톤 · **마지막 장면에서 멈춤** |
| `kiss` | 뽀뽀 (**유료**) | kiss → love → shy | 확대 | 💋❤️💕 |

> 영상을 **언제** 틀지는 `lib/reactionDirector.ts`가 정합니다. 쿨다운, 특별한 순간, 등 돌림/화해, 유료 잠금 규칙이 있습니다. → **`docs/REACTION_VIDEOS.md`**

### 영상 추가하는 법 (나중에 영상 리소스를 만들 때)

1. 리액션 id를 파일 이름으로 해서 넣습니다. 예: `public/avatar/personas/character_e/clips/shy.mp4`
2. 재배포하면 **자동으로 인식**합니다. 빌드할 때 폴더를 스캔하므로 목록을 따로 고칠 필요가 없습니다.
3. 영상 조건은 `docs/VIDEO_AVATAR.md`를 참고하세요. 무음 mp4, 세로, 카메라 고정, 끝에서 시작 자세로 복귀하는 영상이 기준입니다.
4. 우선순위를 정해서 만들면 효율적입니다. 아래 순서를 권장합니다.
   - 먼저 `idle`, `smile`, `laugh`, `nod`
   - 그다음 `shy`, `love`, `pout`, `sad`
   - 나머지는 대체 순서 덕분에 점진적으로 채워도 됩니다. 예를 들어 `love`가 없으면 `shy`, `happy` 순으로 찾습니다.

## 1-1. 화면 터치 리액션 (유저 → 인물)

화면 속 인물을 터치하면 **AI를 부르지 않고 바로** 반응합니다. 그래서 빠르고 비용이 없습니다.
폰에서는 메신저의 빈 곳(말풍선·입력창이 아닌 곳)을 터치해도 됩니다. 보이스톡 중에도 됩니다.

| id | 이름 | 영상 찾는 순서 | 영상이 없을 때 | 효과 |
| --- | --- | --- | --- | --- |
| `shy` | 부끄러움 | touch_shy → shy → smile → happy | 고개 갸웃 + 분홍빛 | 💗☺️💕 |
| `joy` | 즐거움 | touch_joy → laugh → excited → happy | 통통 튐 | ✨😆🎶 |
| `pout` | 앙탈 | touch_pout → pout → angry → shake | 흔들흔들 | 💢😤💨 |
| `lovely` | 사랑스러움 | touch_lovely → love → shy → happy | 확대 + 붉은빛 | ❤️💕🥰💖 |
| `surprised` | 깜짝 | touch_surprised → surprised | 확대 | ❗😳 |

- **터치 효과:** 손가락 자리에 물결이 퍼지고, 이모지가 튀어나가며, 인물 위에 한마디(예: "앗…", "흥!")가 잠깐 뜹니다. 폰에서는 짧게 진동합니다.
- **반응 고르는 기준** (`pickTouchReaction`):
  - **부위:** 화면 위쪽 30%는 머리(쓰다듬기), 30~55%는 얼굴(볼 콕), 그 아래는 몸(간지럼)입니다.
  - **연타:** 1.2초 안에 3번 이상 터치하면 앙탈 확률이 올라가고, 5번 이상이면 무조건 앙탈입니다.
  - **호감도:** 20 미만이면 놀람·부끄러움 위주입니다. 45 이상이고 연애형이면 사랑스러움이 나옵니다. 친구형은 사랑스러움 대신 즐거움으로 반응합니다.
- **인물별 한마디:** `personas/<id>.json`에 `"touchLines": { "shy": ["앗… 왜 그래?"], "pout": ["그만해~!"] }`처럼 넣으면 기본 한마디 대신 씁니다.
- **영상으로 바꾸기:** `public/avatar/personas/<id>/clips/touch_shy.mp4`처럼 `touch_<id>` 영상을 넣으면 다음 배포부터 그 영상이 바로 재생됩니다. 터치 전용 영상이 없으면 일반 리액션 영상(shy, love …)을 대신 씁니다.
- 반응 종류를 늘리려면 `config/reactions.ts`의 `TOUCH_REACTION_DEFS`에 항목을 추가하고, `pickTouchReaction`에서 언제 나올지 정하세요.

## 2. 마음 리액션 (유저 → 상대 메시지)

상대 말풍선을 탭하거나 입력창 옆 ♥ 버튼으로, 말없이 감정을 보냅니다.

| id | 표시 | 이름 |
| --- | --- | --- |
| `love` | ❤️ | 사랑해 |
| `like` | 👍 | 좋아요 |
| `joy` | 😆 | 기뻐 |
| `shy` | ☺️ | 쑥스러워 |
| `pout` | 😤 | 앙탈 |
| `touched` | 🥹 | 감동 |
| `haha` | 🤣 | 웃겨 |
| `hug` | 🫂 | 토닥토닥 |
| `wow` | 😮 | 놀라워 |
| `sad` | 😢 | 슬퍼 |

- **보낼 때:** 화면에 큰 이모지가 튀어나오고 작은 이모지가 떠오릅니다. 그 말풍선에는 배지가 붙습니다. 같은 말풍선에 다시 달면 교체됩니다.
- **AI의 반응:** 호감도와 관계 단계에 맞게 반응합니다. 말없이 표정만 지을 수도 있고(예: 쑥스러움), 짧게 답할 수도 있습니다.
- **AI가 다는 마음:** AI도 가끔 유저의 메시지에 마음을 달아 줍니다(tapback). 유저 말풍선에 배지로 표시됩니다.

## 3. 호감도 (0~100)

- **변화:** AI가 매 턴 `affection_delta`(-5~+5)로 판단합니다. 다정함과 관심은 +, 무례하면 −입니다.
- **저장과 표시:** 대화방마다 저장되고, 헤더의 ♥ 바와 단계 이름으로 표시됩니다.
- **단계별 태도:** 단계에 따라 AI의 태도 지침이 바뀝니다.

| 호감도 | 연애형 (`romance`) | 친구형 (`friendship`) |
| --- | --- | --- |
| 0~19 | 알아가는 중 | 알아가는 중 |
| 20~44 | 편한 사이 | 편한 사이 |
| 45~74 | 설레는 사이 | 친한 친구 |
| 75~100 | 특별한 사이 (연인은 대화로 서로 확인했을 때만) | 절친 |

인물의 유형은 JSON의 `relationshipType`으로 정합니다. 현재 윤지아만 `friendship`입니다.
