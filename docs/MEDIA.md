# 사진·영상 보내기 (앨범 무료 + 실시간 사진 유료)

유저가 "사진 보내 줄래?", "얼굴 보고 싶어", "영상 찍어 보여 줘"라고 하면 인물이 사진이나 영상을 보냅니다.

## 동작 방식

| 유저 요청 | 인물의 반응 | 비용 |
| --- | --- | --- |
| 그냥 보고 싶다는 요청 ("사진 보내 줘", "영상 보여 줘") | "찍어 둔 거 있어요" 하고 **앨범에서 바로** 보냄. 얼굴이 100% 같고, 같은 사진은 되도록 반복하지 않음 | 무료 |
| (멤버십 회원) 지금 모습·앨범에 없는 모습 | 모달에 "구독 혜택으로 받기 (이번 달 N장 남음)" → 멤버십 사진에서 차감 | 무료 (월 한도 안) |
| **지금 모습**이나 **앨범에 없는 모습** ("지금 뭐 입었어? 찍어 줘", "카페에 있는 모습") | 말풍선으로 "잠깐만요, 찍어 볼게요"라고 한 뒤, 채팅이 아닌 **앱 모달**로 유료 안내 → 확인하면 캐시 차감 → 인물 사진을 기준으로 새 사진 생성해서 보냄 | 💎 10 (`config/media.ts`) |
| 노출이나 선정적인 요청 | 부드럽게 거절. 아무것도 보내지 않음 | — |

- 어떤 경우인지는 AI가 답장할 때 함께 판단합니다(`media_action`). 돈이나 결제 이야기는 인물이 하지 않고, 앱 모달이 안내합니다.
- 모달에서 **다음에**를 누르면 "사진 받기를 취소했어요" 안내만 남습니다(AI에게는 보내지 않음).
- 생성에 실패하거나 안전 필터에 걸리면 **캐시를 자동 환불**합니다.
- 생성 사진에는 "AI 생성" 표시가 붙습니다. 사진이나 영상을 누르면 크게 볼 수 있습니다.
- 보낸 사진·영상은 대화 기록에 남아서, 이후 대화에서 인물이 "아까 보낸 사진"을 기억합니다.

## 앨범 등록 (인물별, 코드 수정 없음)

1. 파일을 `public/avatar/personas/<id>/album/`에 넣습니다. 영상은 리액션 클립(`clips/…`)을 그대로 가리켜도 됩니다.
2. `personas/<id>.json`에 `album` 목록을 추가합니다. `desc`가 구체적일수록 AI가 상황에 맞는 걸 잘 고릅니다.

```json
"album": [
  { "id": "sunset_smile", "type": "photo", "file": "album/sunset_smile.jpg", "desc": "노을 지는 강변 언덕에서 환하게 웃는 셀카" },
  { "id": "hello_video",  "type": "video", "file": "clips/love.mp4",         "desc": "노을 앞에서 수줍게 웃는 짧은 영상" }
]
```

서하린에는 사진 5장(리액션 영상에서 뽑은 4장 + 대표 사진)과 영상 2개가 등록되어 있습니다.
**앨범이 다양할수록 무료 경험이 좋아지고**, 앨범에 없는 걸 원할 때 유료로 자연스럽게 넘어갑니다. 인물마다 일상 사진(카페, 출근길, 잠옷 아닌 편한 옷, 운동 후 등)을 10~20장 정도 권장합니다.

## 실시간 사진이 얼굴을 맞추는 방법

`/api/media/photo`가 인물의 기존 사진 최대 4장(`stage.jpg` → 앨범 사진 → 대표 사진 순)을 **기준 이미지**로 넣습니다. 그리고 "정확히 같은 사람"을 강하게 지시해서 새 사진을 만듭니다.

- 모델: `GEMINI_IMAGE_MODEL` (기본 `gemini-3.1-flash-image`)
- 비용: 2026년 10월 Google 가격표 기준 1장에 약 $0.045~0.07. 생성 시간은 보통 5~15초입니다.
- 생성 이미지라서 기준 사진과 **100% 똑같지는 않습니다.** 얼굴이 일정한 고화질 기준 사진을 여러 장(정면·측면) 넣을수록 정확해집니다.
- 실제 인물(연예인)과 닮은 이미지는 만들지 않도록 프롬프트로 막아 두었고, Google의 안전 필터도 함께 적용됩니다.

## 설정 (환경변수)

| 변수 | 설명 | 기본값 |
| --- | --- | --- |
| `GOOGLE_GENERATIVE_AI_API_KEY` | 필수 (보이스톡과 같은 키) | — |
| `GEMINI_IMAGE_MODEL` | 이미지 모델 | `gemini-3.1-flash-image` |
| `MEDIA_ACCESS` | `open`(누구나) / `paid`(`VOICE_DEV_PASS` 헤더만 통과) / `off` | 개발 `open`, 배포 `paid` |

배포 환경에서 테스트하려면 Vercel에 `MEDIA_ACCESS=open`을 추가하고 Redeploy 하세요.

## ⚠️ 결제 연동 전 주의 (지금은 테스트용)

- **캐시는 지금 브라우저에만 저장됩니다**(`lib/wallet.ts`). 시작 캐시는 💎 100이고, 모달의 "충전"은 테스트용입니다. 유저가 값을 조작할 수 있으므로 실제 판매에는 쓰면 안 됩니다.
- 실제 판매 시 할 일:
  1. 로그인과 서버 DB에 잔액을 둡니다.
  2. `/api/media/photo`가 생성 전에 **서버에서 차감**하고, 실패하면 서버에서 환불하게 바꿉니다.
  3. `lib/entitlements.ts`의 `checkMediaAccess`를 사용자 확인으로 바꿉니다.
- 생성 사진은 지금 브라우저 저장소에 압축 이미지(약 100KB)로 저장됩니다. 저장 공간이 부족하면 사진만 빼고 대화를 저장합니다. 서비스 시에는 Vercel Blob이나 S3 같은 저장소에 올리고 URL만 기록하세요.

## 유저가 사진·영상을 보내면 (AI 반응)

메신저 입력창 왼쪽 **🖼 버튼**으로 사진이나 영상을 보낼 수 있습니다. 입력창에 쓴 말이 있으면 함께 보냅니다.

- 인물이 사진·영상을 **실제로 보고** 자기 성격대로 말로 반응합니다(`traits.mediaReaction`). 마음에 들면 사진에 ❤️·😮 같은 마음을 달고, 표정 영상(리액션)도 나옵니다.
- 영상은 앞·중간·뒤 장면(기본 3장)을 AI에게 보여 줍니다. 소리는 보내지 않습니다.
- AI가 본 내용은 한 줄로 기억해 두고(`seen`), 다음 대화에서 "아까 보낸 사진"을 이어서 이야기할 수 있습니다.
- **보관:** 파일은 이 기기의 브라우저 저장소(IndexedDB)에 남아 다시 열어도 보입니다. 대화방 **"처음부터"** 를 누르면 같이 지워집니다. 다른 기기에서는 보이지 않습니다.
- **서버로 가는 것:** AI 판단용으로 줄인 JPEG 장면만 보냅니다. 원본 파일은 서버에 저장하지 않습니다.
- 노출·성적인 사진은 인물이 내용을 언급하지 않고 부드럽게 넘깁니다. 사람 얼굴은 다정하게만 말하고 누구인지 추측하지 않습니다.
- 크기·개수 제한과 호감도 상한은 `config/balance.json` 의 `userMedia` (docs/BALANCE.md §7).
- AI 모델이 이미지를 이해해야 합니다. 지금 쓰는 Bedrock Nova Lite·Gemini 모두 지원합니다.

## 나중에: 실시간 영상

"영상 찍어 줘"의 실시간 생성(예: Gemini Omni Flash, 720p 약 $0.10/초)도 같은 구조로 붙일 수 있습니다. `MediaDirective`에 `type: "video"`를 추가하고 `/api/media/video`를 만들면 됩니다. 영상은 생성에 1~2분 걸리므로 "찍어서 보낼게요" → 완성되면 도착하는 흐름이 자연스럽습니다.
