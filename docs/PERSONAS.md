# 멀티 페르소나 시스템

> 캐릭터 내용 수정, 추가, 숨기기는 **`personas/README.md`** 를 보세요. 캐릭터 1명이 JSON 파일 1개입니다.

## 콘셉트

**정해진 인물과 메신저(톡)로 대화하며 교감하고 관계를 키워 가는 앱**입니다.
- 현실에서는 만날 수 없는 사이라는 전제로, 메시지를 주고받으며 서로의 하루를 나눕니다.
- 관계는 천천히 자랍니다: 막 알게 된 사이 → 편한 친구 → 설레는 사이 → 연인. 유저의 속도를 따릅니다.
- 좌측의 사진과 영상은 **답장에 맞춰 반응하는 리액션 화면**입니다.
- 답장은 말풍선 1~3개로 나뉘어 "입력 중…" 표시와 함께 도착합니다.
- 대화는 인물마다 브라우저에 따로 저장돼서 다시 와도 이어집니다.
- 각 인물은 자기 시간대의 현재 시각을 알고 그에 맞게 말합니다(다니엘은 뉴욕 시간).
- **이어지는 대화:**
  - 나갔다 들어오면 대화방이 그대로 이어집니다.
  - 시간 경과("4시간 뒤")가 AI에 전달됩니다.
  - 3시간 이상 비웠다가 열면 상대가 먼저 말을 겁니다.
  - 답장을 받지 못하고 나갔다면 다시 열 때 상대가 이어서 답합니다.
  - 다른 방으로 옮긴 사이에 온 답장도 원래 방에 저장됩니다.
- **마음 리액션·화면 리액션·호감도:** `docs/REACTIONS.md`
- **화면:** 폰과 세로 화면은 인물이 배경에 깔리고 그 위에 채팅이 겹칩니다. 가로로 넓은 화면(가로 휴대폰 포함)은 좌우 분할입니다.

### 안전 장치 (route.ts)

- **AI 여부:** 진지하게 "AI야?"라고 물으면 부정하지 않습니다.
- **만남·연락처:** 현실 만남, 통화, 연락처 요청은 부드럽게 거절하고, 유저의 개인정보는 묻지 않습니다.
- **돈:** 돈이나 선물을 요구하지 않습니다.
- **위기 대응:** 위기 신호가 보이면 109(자살예방 상담전화)와 119를 안내합니다.
- **조종 금지:** 질투, 죄책감, 집착으로 유저를 붙잡지 않고, 현실의 관계를 응원합니다.
- **표현 수위:** 애정 표현은 괜찮지만 노골적인 성적 대화는 하지 않습니다.
- **미성년자:** 미성년자로 보이면 연애로 흐르지 않습니다.

## 구조

| 파일 | 역할 |
| --- | --- |
| `personas/<id>.json` | 캐릭터 1명의 모든 데이터 (공개 정보 + 프롬프트) |
| `personas/_shared.json` | 모든 캐릭터 공통 규칙 (메신저로 알게 된 사이, 현실 세계, 고정관념·실존 인물 금지 등) |
| `personas/index.ts` | 등록 목록 (순서 = 선택 화면 순서, 첫 번째 = 기본) |
| `lib/personas/server.ts` | **서버 전용** 로더: 파일 검증, 공개 정보와 프롬프트 분리 |
| `app/page.tsx` | 서버 컴포넌트: 공개 정보만 브라우저로 전달 |
| `app/api/chat/route.ts` | `personaId` 검증 → 캐릭터 프롬프트 + 공통 규칙 + 대화 원칙·안전 규칙으로 시스템 프롬프트 구성 |
| `components/PersonaSelector.tsx` | 대화 목록 (전체·여성·남성 필터, 대화 중 표시, 마지막 메시지 미리보기) |
| `components/ChatApp.tsx` | 대화방 저장/복원, 말풍선 순차 표시, 시간대 전달 |
| `components/ChatPanel.tsx` | 메신저 UI (프로필, 시간, 날짜 구분선, 입력 중 표시) |

- 대화와 호감도는 인물별로 `localStorage`의 `ai-rpg.chat.<id>`에 저장됩니다(형식 v2, 최대 300개). 예전 형식은 자동으로 변환되고, AI에는 최근 40턴을 보냅니다. "처음부터"를 두 번 누르면 그 대화방만 지워집니다.
- 저장은 **이 브라우저에만** 됩니다. 다른 기기에서 이어서 하려면 로그인과 서버 DB가 필요합니다(다음 단계 후보).
- 첫 메시지(greeting)는 화면에만 표시하고 API 히스토리에서는 뺍니다. 대신 서버 프롬프트에 넣어 대화가 이어지게 합니다.
- 알 수 없는 `personaId`는 400을 반환하고, 생략하면 기본 캐릭터로 처리합니다.

## 폴백 순서 (파일이 없거나 로딩 중일 때)

1. **클립:** `clips/` → `fallbackClipsDir`(지정한 경우) → 없음
2. **이벤트 클립이 없을 때:** 화면 전체에 가벼운 CSS 리액션(끄덕임, 도리도리, 놀람 등)
3. **idle 클립이 없을 때:** 정지 이미지 + 미세한 호흡 모션
4. **정지 이미지:** `poster` → `fallbackPoster` → 텍스트 카드(이니셜, 이름, "이미지 준비 중")

> ⚠️ `fallbackClipsDir` / `fallbackPoster`에는 **반드시 같은 인물의 자원만** 지정하세요. 다른 인물을 지정하면 선택한 캐릭터와 다른 얼굴이 재생됩니다.
> 현재 `character_a`만 기존 `/avatar/clips`(같은 노을 배경 캐릭터로 만든 임시 클립)를 폴백으로 씁니다.
