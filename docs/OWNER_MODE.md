# 🔑 주인님 모드 (치트)

대화 중 `OWNER_CHEAT_PHRASE`(기본 `shout4all주인님등장qqqq1111`)가 들어간 메시지를 보내면, 서버가 주인으로 인식합니다. 인물의 성격·말투는 그대로 두고, 대화 범위 제한만 풀어 무엇이든 그 인물 말투로 답합니다. 안전 규칙은 유지됩니다. 전체 스위치 표는 `docs/MODES.md`.

- 문구는 **서버에서만** 비교합니다. 앱 번들에는 들어 있지 않고, 앱은 서버가 준 인증 토큰(HMAC)만 기기에 저장해 이후 요청에 붙입니다.
- 해제: 주인님 모드에서 `주인님퇴장` 을 보내면 꺼집니다.
- **출시 전 필수**: Vercel 환경변수 `OWNER_CHEAT_PHRASE` 에 새 문구를 넣으세요. 이 문서·코드의 기본 문구는 유출된 것으로 보고 바꿔야 합니다. (`lib/owner.ts`)

## 🔑 치트룸 (윤지아 TEST)

윤지아와 같은 캐릭터·같은 사진/영상 리소스(`public/avatar/personas/cheat_b/`)를 쓰는 **운영자 전용 테스트방**입니다. 평소엔 대화 목록에 보이지 않습니다.

- **입장**: 대화 목록 맨 아래 `🔑 코드 입력` → 치트 코드(`OWNER_CHEAT_PHRASE`) 입력 → 방이 나타나고 바로 들어갑니다. (대화 중에 코드를 보내도 같은 토큰이 생겨 목록에 나타납니다.) 코드는 서버에서만 비교하고, 1분에 8번까지만 시도할 수 있습니다.
- **퇴장**: `주인님퇴장` → 토큰이 지워지고 방이 목록에서 사라집니다.
- **서버도 막습니다**: 운영자 인증이 없으면 이 방의 대화(`/api/chat`)와 보이스톡(`/api/voice/session`)이 거절됩니다. 숨김은 화면만의 문제가 아닙니다.
- **치트 기능**: 💎·멤버십·성인 확인이 모두 풀림(특별 리액션·매혹 모드 사용 가능). 🛠 관리창에 `🔑치트` 탭 — 호감도 슬라이더, 💎+1000, 삐짐 풀기, 대화 처음부터.
- **제한 조정(3겹)**
  1. 파일 기본값: `personas/cheat_b.json` 의 `cheatRules`(이 방의 "주인님 모드 규칙")와 `prompt.*`
  2. CMS 저장값: `setPersistedOverrides({ personas: { cheat_b: {...} }, rules: {...} })`
  3. 🛠 테스트값: 🛠 › **규칙** 탭(주인님 모드 규칙·절대 수칙 등)·**캐릭터** 탭 — 고치면 다음 메시지부터 즉시 적용
  - 미성년자 관련 줄(`MINOR_GUARD`)만 코드에 고정이라 고칠 수 없습니다.
- **모델**: 성인 모델(`AI_MODEL_MATURE`)이 설정돼 있으면 이 방은 그 모델로 먼저 시도하고, 없으면 메인 모델입니다. 🛠 › 모델 탭에서 Grok·Llama 등을 골라 바꿔 가며 시험할 수 있습니다.
- 이 방은 선톡 알림 대상이 아니고, 앱을 다시 열 때 자동으로 복원되지도 않습니다.
- 보이스톡(Gemini Live)은 방 접근만 열어 둔 것이고, 대화 수위는 Gemini 쪽 정책을 따릅니다.
