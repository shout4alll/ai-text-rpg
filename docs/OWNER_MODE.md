# 🔑 주인님 모드 (치트)

대화 중 `OWNER_CHEAT_PHRASE`(기본 `shout4all주인님등장qqqq1111`)가 들어간 메시지를 보내면, 서버가 주인으로 인식해 인물 연기를 벗고 범용 AI 로 모든 질문에 답합니다. 안전 규칙은 그대로 유지됩니다.

- 문구는 **서버에서만** 비교합니다. 앱 번들에는 들어 있지 않고, 앱은 서버가 준 인증 토큰(HMAC)만 기기에 저장해 이후 요청에 붙입니다.
- 해제: 주인님 모드에서 `주인님퇴장` 을 보내면 꺼집니다.
- **출시 전 필수**: Vercel 환경변수 `OWNER_CHEAT_PHRASE` 에 새 문구를 넣으세요. 이 문서·코드의 기본 문구는 유출된 것으로 보고 바꿔야 합니다. (`lib/owner.ts`)
