# 유료 정책 — 무료 체험 · 캐시 · 멤버십(BEST · PRIME · VIP)

모든 숫자는 **`config/plans.ts`** 한 파일에서 바꿉니다.

## 1. 보이스톡

| 순서 | 조건 | 과금 |
| --- | --- | --- |
| ① 무료 체험 | 처음 한 번, 통화 횟수와 상관없이 **주고받기 5번**까지 | 무료 |
| ② 멤버십 | 이번 달 남은 통화 시간이 있으면 | 구독 시간에서 차감 (BEST 30분 / PRIME 120분 / VIP 300분) |
| ③ 캐시 | 둘 다 없으면 멤버십·캐시 안내 모달 → "💎5/분으로 통화하기" | 시작할 때 1분, 이후 1분 넘어갈 때마다 💎5 |

- **주고받기 1번**은 인물이 실제로 말을 마친 횟수입니다. 인사만 하고 끊어도 1번입니다.
- 5번째 답을 다 들려준 뒤 통화가 끝나고, 곧바로 **"무료 보이스톡 체험이 끝났어요"** 멤버십 안내가 뜹니다.
- 무료 체험 통화는 서버에서도 최대 3분으로 제한합니다(브라우저 조작 대비).
- 구독 시간이나 캐시가 바닥나면, 하던 말을 마저 들려준 뒤 끊고 안내 모달을 띄웁니다. 통화 화면에는 남은 회차·시간·과금 방식이 표시됩니다.
- 캐시 통화가 연결에 실패하면 먼저 낸 1분은 돌려줍니다.

## 2. 실시간 사진

멤버십 사진이 남아 있으면 **"구독 혜택으로 받기"**(이번 달 남은 장수 표시), 없으면 💎10 캐시로 받습니다. 실패하면 사진 장수나 캐시를 돌려줍니다.

## 3. 멤버십 단계 (기본값)

| | BEST | PRIME | VIP |
| --- | --- | --- | --- |
| 월 구독료 | ₩9,900 | ₩19,900 | ₩39,900 |
| 보이스톡 | 30분 | 120분 | 300분 |
| 실시간 사진 | 10장 | 40장 | 100장 |
| 특별 리액션 영상(뽀뽀 등) | ✗ | ✓ | ✓ |
| 매달 보너스 캐시 | — | 💎50 | 💎150 |
| 다 썼을 때 원가 (추정) | 약 1,800원 | 약 7,000원 | 약 17,600원 |

- 원가는 2026년 10월 Google 가격 기준 추정치입니다. 보이스톡 1분 ≈ 32원, 사진 1장 ≈ 60~100원, 환율 1,400원으로 계산했습니다. 앱스토어 수수료(최대 30%)를 빼도 남도록 잡았습니다. 대부분 한도를 다 쓰지 않으므로 실제 마진은 더 큽니다.
- 헤더의 **멤버십 / 👑 PRIME** 배지를 누르면 언제든 멤버십 안내를 볼 수 있습니다.
- 매달 1일(UTC 기준 달이 바뀔 때) 이번 달 사용량이 초기화됩니다. 무료 체험은 초기화되지 않습니다.

## ⚠️ 지금은 테스트용입니다 — 판매 전에 꼭 할 일

지금 멤버십 상태(`lib/membership.ts`)와 캐시(`lib/wallet.ts`)는 **브라우저에만 저장**됩니다. "구독하기"·"충전" 버튼은 결제 없이 바로 적용되는 테스트 버튼입니다. 유저가 값을 바꿀 수 있으므로 그대로 판매하면 안 됩니다.

1. **로그인 붙이기** — 예: Supabase Auth, NextAuth, 카카오/구글 로그인
2. **서버 DB에 저장** — 구독 단계, 이번 달 사용량, 무료 체험 사용 수, 캐시 잔액
3. **결제 연동**
   - 웹: 토스페이먼츠·포트원 정기결제
   - 앱 출시 시: App Store / Google Play 구독(인앱결제 의무)
   - 결제 완료 웹훅에서 서버가 구독 단계를 바꿉니다.
4. **서버에서 차감·검증** — 아래 API가 시작 전에 잔액·한도를 확인하고 차감하게 바꿉니다.
   - `/api/voice/session`: 통화 시작 시 남은 체험/시간/캐시 확인. 통화 길이를 토큰 만료로 제한합니다(`maxSeconds`).
   - 통화 종료 보고 API를 추가해서 실제 사용 시간을 정산합니다.
   - `/api/media/photo`: 생성 전에 차감하고, 실패하면 환불합니다.
5. `lib/membership.ts`, `lib/wallet.ts`의 함수 이름은 그대로 두고 내부만 서버 API 호출로 바꾸면 화면 코드는 고칠 필요가 없습니다.
