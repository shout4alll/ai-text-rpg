# 캐릭톡 밸런스 데이터 가이드

호감도·삐짐·보상·리액션 빈도·가격 같은 **조절 가능한 숫자는 전부 `config/balance.json` 한 파일**에 있습니다.
인물마다 다른 성향(좋아하는 것, 선물, 표정 빈도 등)은 `personas/<id>.json`의 `traits`에 있습니다.

## 0. 조정하는 방법

| 방법 | 하는 일 |
| --- | --- |
| **A. 직접 수정** | `config/balance.json`의 숫자를 바꾸고 재배포합니다. 형식이 틀리면 빌드가 "어느 항목이 왜 틀렸는지" 알려 줍니다. |
| **B. 저에게 보내기** | 이 문서 맨 아래 **조정 요청 양식**의 "바꿀 값" 칸을 채워 보내 주세요. 그대로 반영합니다. |

- 시간 단위: `Ms`로 끝나면 밀리초(1000 = 1초), `Min`은 분, `Sec`는 초입니다.
- 확률(`Chance`)은 0~1입니다. 0.65 = 65%.
- 재배포 전까지는 바뀌지 않습니다. 개발 서버는 다시 시작하면 됩니다.

## 1. 호감도 (`affection`)

호감도는 0~100입니다. 상대가 답장할 때마다 AI가 "이번 말이 준 느낌"(−5~+5)을 정하고, 아래 규칙으로 보정해 반영합니다.

```
최종 변화 = 반올림( AI 값 × 배수 ) → 상황별 상한 → 턴 상한(±stepCap)
```

| 키 | 현재 | 설명 |
| --- | --- | --- |
| `start` | 10 | 첫 대화 시작 호감도 |
| `stepCap` | 5 | 한 번에 오르내릴 수 있는 최대치 (±) |
| `gainMultiplier` | 1.0 | 오를 때 배수. 1.5로 하면 50% 빨리 오름 |
| `lossMultiplier` | 1.0 | 내려갈 때 배수 |
| `gainWhileSulking` | 0.5 | 삐져 있을 때 오르는 양 배수 (0.5 = 절반만) |
| `heartReactionMaxGain` | 2 | 마음 리액션(❤️ 등)만 보냈을 때 최대 상승 |
| `stageUpBannerMs` | 4000 | 단계 상승 배너 표시 시간 |
| `stageDownNotice` | true | 단계가 내려가면 "관계가 조금 멀어졌어요" 안내 |

AI가 주는 기준은 이렇습니다. 관심·배려·다정함은 +1~+3, 평범한 대화는 0, 무례하거나 상처 주는 말은 −1~−5예요. 인물이 **좋아하는 이야기**에는 조금 더 주고, **싫어하는 말**에는 음수를 줍니다(§4).

### 1-1. 단계와 보상 (`affection.stages`)

연애형(`romance`)과 친구형(`friendship`)이 따로 있습니다. 각 단계는 `min`(시작 점수), `label`(이름), `guide`(AI 태도), `reward`(보상)로 되어 있어요.

| 연애형 | min | 처음 올라설 때 보상 | 친구형 | min | 보상 |
| --- | --- | --- | --- | --- | --- |
| 알아가는 중 | 0 | — | 알아가는 중 | 0 | — |
| 편한 사이 | 20 | 웃음 영상 | 편한 사이 | 20 | 웃음 영상 |
| 설레는 사이 | 45 | 설렘 영상 + 💎5 | 친한 친구 | 45 | 웃음 영상 + 💎5 |
| 특별한 사이 | 75 | 💋 뽀뽀 영상(유료, 없으면 설렘) + 💎10 | 절친 | 75 | 감동 영상 + 💎10 |

- 단계가 오르면 **배너 + 특별 리액션 영상 + 보너스 캐시 + 인물의 단계 한마디**(`traits.stageUpLines`)가 나옵니다.
- 보상은 그 단계에 **처음 올라설 때만** 줍니다. 떨어졌다가 다시 올라오면 "다시 가까워졌어요" 안내만 나와요(보상 반복 방지).
- `reward.reaction`에 쓸 수 있는 값: `smile laugh shy love touched excited kiss` 등 (§9 목록).
- 화면에는 `♥ 23`, 막대(이번 단계 안에서의 진행률), `편한 사이 (22)`(다음 단계까지 남은 점수)가 보입니다.

**참고 속도:** AI가 보통 +1~+2를 주므로 다정한 대화 기준으로 편한 사이까지 약 5~10번, 설레는 사이까지 약 20~30번, 특별한 사이까지 약 40~60번 주고받아야 해요. 더 빠르게 하려면 `gainMultiplier`를 올리거나 단계 `min`을 낮추세요.

## 2. 삐짐 (`sulk`)

상대가 서운하면 **등을 돌린 채 멈춰** 있고, 유저가 달래야 풀립니다. 단계가 깊을수록 풀기 어렵습니다.

### 2-1. 언제 삐지나

- AI가 등 돌림을 골랐고 호감도가 떨어졌을 때, 또는 호감도가 `startDrop`(−3) 이하로 떨어졌을 때
- 터치 연타가 `director.touchTurnAwayCombo`(9번) 이상일 때 → 터치 삐짐(`sulk.touch`)

### 2-2. 몇 단계로 삐지나

```
단계 = 떨어진 정도(levelByDrop) + 관계 단계 보너스(levelBonusByStage) + 반복 가중(+1)   (최대 3)
```

| 키 | 현재 | 설명 |
| --- | --- | --- |
| `startDrop` | −3 | 이만큼 떨어지면 AI가 등 돌림을 안 골라도 삐짐 |
| `levelByDrop` | −1→1단계, −3→2단계, −5→3단계 | 떨어진 양에 따른 기본 단계 |
| `levelBonusByStage` | [0, 0, 1, 1] | 관계 단계별 추가 (알아가는/편한/설레는/특별한). **가까워질수록 더 깊게 삐짐** |
| `escalateWindowMin` | 30 | 풀린 뒤 이 시간(분) 안에 또 삐지면 +1단계 |
| `sootheDelta` | 2 | AI 판단 외에도 호감도가 이만큼 오르는 말이면 "달래는 말"로 인정 |

→ 초반(알아가는 중)엔 대부분 1~2단계라 하트·말로 풀리고, 가까워진 뒤엔 2~3단계라 진심 어린 말이나 선물이 필요해요.

### 2-3. 단계별 푸는 방법 (`sulk.levels`)

| 단계 | 이름 | 무료로 풀기 | 필요한 달래는 말 | 선물 비용 | 저절로 풀림 |
| --- | --- | --- | --- | --- | --- |
| 1 | 살짝 삐짐 | ❤️ 사랑해 · 👍 좋아요 · 🫂 토닥 · 🥹 감동 · ☺️ 쑥스러워 | 1번 | 💎3 | 30분 |
| 2 | 토라짐 | (하트로는 안 풀림) | 1번 | 💎5 | 3시간 |
| 3 | 단단히 화남 | (하트로는 안 풀림) | 2번 | 💎10 | 12시간 |

- `freeHearts`: 이 단계에서 풀리는 마음 리액션 목록. 빈 배열이면 하트로는 안 풀려요. (쓸 수 있는 값: `love like joy shy pout touched haha hug wow sad`)
- **달래는 말**: AI가 "진심으로 달래 줬다"고 판단하거나(soothed), 호감도가 `sootheDelta` 이상 오른 말입니다. 3단계는 2번 필요하고 화면에 (1/2)처럼 표시돼요.
- `hint`: 화면 안내 문구입니다.
- `autoReleaseMin`: 대화방을 다시 열었을 때 이 시간이 지났으면 저절로 풀려요. 0이면 저절로 안 풀림.
- 삐져 있는 동안엔 호감도가 절반만 오릅니다(`affection.gainWhileSulking`).

### 2-4. 선물 (`sulk.gift`) — 유료로 즉시 풀기

삐짐 안내창의 **🎁 선물 버튼**으로 캐시를 쓰면 바로 풀리고 특별 리액션이 나옵니다. 선물 이름은 인물마다 다릅니다(§4).

| 키 | 현재 | 설명 |
| --- | --- | --- |
| `affectionBonus` | 2 | 선물하면 호감도 + |
| `reaction` | love | 풀릴 때 리액션 |
| `kissIfPossible` | true | 뽀뽀 영상 조건(연애형·호감도 75+·유료)이 되면 뽀뽀로 |

### 2-5. 터치 삐짐 (`sulk.touch`)

| 키 | 현재 | 설명 |
| --- | --- | --- |
| `level` | 1 | 터치 연타 삐짐 단계 |
| `autoReleaseSec` | 20 | 이 시간(초) 뒤 저절로 풀림 |

## 4. 인물별 성향 (`personas/<id>.json` → `traits`)

| 키 | 하는 일 |
| --- | --- |
| `likes` | 좋아하는 것 → 이 이야기엔 더 신나고 호감도가 잘 오름 |
| `dislikes` | 싫어하는 것 → 서운해함(호감도 −) |
| `soothe` | 삐졌을 때 잘 풀리는 말·행동 |
| `sulkStyle` | 삐졌을 때 말투 |
| `gift` | 달래기 선물 이름·이모지 |
| `reactionBias` | 표정별 **영상 확률 배수** (1 = 기본, 1.5 = 더 자주, 0.5 = 덜). AI에게도 "자주 짓는 표정"으로 알려 줌 |
| `stageUpLines` | 단계가 처음 오를 때 하는 말 (2번째·3번째·4번째 단계 순서) |
| `mediaReaction` | 유저가 사진·영상을 보냈을 때 반응 방식 |
| `touchLines` (traits 밖) | 터치했을 때 머리 위 한마디 (shy·joy·pout·lovely·surprised) |

**현재 설정 요약**

| 한소율 | 연애 | 🎮 한정판 게임 굿즈 | 웃음 1.5, 신남 1.4, 삐짐 1.2 | 부끄러움 0.9 |
| 정다온 | 연애 | 🧁 디저트 박스 | 신남 1.4, 웃음·놀람 1.3, 생각 1.2 | — |

좋아하는 것·싫어하는 것·달래는 말·단계 한마디 전문은 각 인물 파일에서 확인·수정하세요.
